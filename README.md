# Sente（先手）

### つくりたいことを伝える。コードを読み、直し、確かめる。

日本語でも、声でも使えるAIコーディングエージェントです。作業するフォルダで依頼すると、ファイルの調査・編集・コマンド実行を通じて開発を進めます。用途に合わせて、使うAIモデルを切り替えられます。

**[はじめる](#start) · [使い方](#examples) · [モデル切替](#models) · [本体ソース](https://github.com/yukihamada/opencode/tree/headless-model-fallback) · [English](./README.en.md)**

![Senteのターミナル画面](./assets/terminal.png)

| こんなときに | 頼めること |
|---|---|
| 初めて触るリポジトリ | 「構成と起動方法を調べて。まず説明だけして」 |
| バグを直したい | 「再現条件を確認して、原因を直し、関連テストを実行して」 |
| ページや機能をつくりたい | 「この画面をスマホでも使いやすくして。変更を確認できるようにして」 |
| 作業の続きを進めたい | `te resume` で直前のセッションを再開 |

> このリポジトリは **導入ガイド・ランチャー・macOSメニューバーアプリ**の公開場所です。ターミナル画面とエージェントの本体は、別の[公開リポジトリ](https://github.com/yukihamada/opencode/tree/headless-model-fallback)にあります。

<a id="start"></a>
## まず動かす

### 1. インストール

macOS、Linux、WindowsのWSLで、ターミナルに貼り付けます。

```sh
curl -fsSL https://teai.io/te | sh
```

必要なものは **`curl` と `python3`**。不足している場合はインストーラの案内に従ってください。文字入力で始めるならマイクは不要です。

スクリプトを確認してから実行する場合：

```sh
curl -fL --max-time 120 https://teai.io/te -o sente-install.sh
less sente-install.sh
sh sente-install.sh
```

### 2. 登録する

```sh
te register
```

メールアドレスと、届いた確認コードを入力します。登録済みなら `te login` を使います。

**ソースコードはMITライセンス。AI・音声などのサービス利用料は別です。** この導入手順はteai.ioを利用します。料金は[料金ページ](https://teai.io/pricing)、残高・利用状況は `te stats` で確認できます。

### 3. プロジェクトのフォルダで起動

ターミナルで作業したいプロジェクトのフォルダへ移動してから：

```sh
te
```

開いた画面に、まず次を入力してみてください。

> このプロジェクトの構成、起動方法、テスト方法を調べて説明してください。まだファイルは変更しないでください。

構成や実行方法が返ってきたら、次にやりたい変更を頼みます。ツール実行の確認が出たら内容を確認して進めてください。

<a id="examples"></a>
## 実際の仕事を頼む

対話しながら進めるなら `te`。依頼を一つ渡して実行するなら `te run` です。

```sh
# 実装と確認をまとめて依頼
te run "このページのスマホ表示を改善して。既存のテストを実行し、変更点を説明して"

# バグの調査から修正まで
te run "失敗しているテストの原因を調べ、必要な修正をして、関連テストを再実行して"

# 続きから再開
te resume
```

**目的・対象・完了条件**を一緒に書くと伝わりやすくなります。例えば「ログイン画面のエラーを分かりやすく。既存デザインに合わせ、失敗時の表示も確認して」のように頼めます。

変更後は差分とテスト結果を確認してください。必要な依存関係・アクセス権・接続先によって、完了できる範囲は変わります。

<a id="models"></a>
## モデルを切り替える

軽い修正、複雑な設計、長いコードの調査。同じ作業環境で、仕事に合わせてモデルを選べます。

| ターミナル画面の基本操作 | 内容 |
|---|---|
| **F2 / Shift+F2** | 最近使ったモデルの次 / 前へ |
| **Ctrl+X → M** | モデル一覧を開く（順番に押します） |
| **F1** | 音声読み上げのON/OFF |
| **Shift+F1** | ヘルプ |

配布版や個人設定でキー割り当てが異なる場合があります。MacでFキーが明るさ等に割り当てられている場合は、Fnキーを併用してください。

コマンドからも選べます。

```sh
te models           # 利用できるモデルIDを確認
te model            # 現在の既定モデルを確認
te model teai/auto  # 自動選択を既定にする
```

特定のモデルを既定にする場合は `te model <モデルID>`。一覧に表示されたIDを使ってください。モデルの提供状況・料金は変わるため、READMEに固定のランキングは置いていません。

## 声で使う（任意）

```sh
koe                 # 声の連続対話。終了はCtrl+C
te voice off        # 読み上げを止める
te voice on         # 読み上げを有効にする
te voice enroll     # 自分の声の登録ページを開く
```

録音には **マイクとSoX**、音声機能には対応する再生環境とサービス接続が必要です。`te doctor` で不足を確認できます。声の登録は任意で、文字だけでも使えます。

## 「SenteでSenteを改善する」開発

Sente自身の開発にもSenteを使っています。実際の仕事で見つかった詰まりを、次の改善につなげます。

```text
使う → 詰まりを見つける → コードを直す → テスト・実測 → 次の版へ
```

この改善の循環を「再帰的な自己改善」と呼んでいます。人が目的を決め、変更をレビューして育てる開発方法です。インストールすると無条件に自己書換え・公開を始める、という意味ではありません。

開発の狙いは、指示から完成までの往復を減らすこと。速さはモデル・仕事・環境に左右されるため、一律の速度倍率は約束していません。

## 困ったとき

| 症状 | 最初に確認すること |
|---|---|
| `te: command not found` | ターミナルを開き直す。続く場合はインストーラが案内したPATHを確認 |
| 認証エラー | `te login` |
| 残高不足・利用できないモデル | `te stats` と `te models` |
| 声が出ない・録音できない | `te doctor`、マイク許可、`te voice on` |
| キー操作が説明と違う | Shift+F1、端末のFnキー設定、個人設定を確認 |
| 更新したい | `te update` を実行し、Senteを再起動 |

Windowsでは、まずWSL内で上の手順を使ってください。[ネイティブ本体の配布](https://github.com/yukihamada/opencode/releases)もありますが、シェルランチャーやmacOSアプリとは別です。
